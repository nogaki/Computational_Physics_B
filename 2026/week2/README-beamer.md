# 第2回スライド（Beamer版）

[2025年度の第2回PDF](../../2025/week2/week2.pdf)を元に、[共通テンプレート](../../templates/beamer/README.md)で作成しています。表紙1枚と本文18枚の全19枚です。
講義日は、10月20日の出張による休講に伴い、2026年10月27日へ変更しています。
講義予定は12月1日を授業日（数値積分）とし、2月9日の補講は行いません。12月8日以降のトピックは元の予定を維持します。

- `slide.tex`：編集用のLaTeXソース。コードもこのファイル内で編集できます。
- `slide.pdf`：配布用PDF。
- `week2.ipynb`：スライドに対応する実習ノートブック。練習問題の解答用セルも用意しています。
- `../../templates/beamer/blue-lecture-theme.tex`：共通の表紙・見出し・フォント・ページ番号設定。

本文はUD デジタル 教科書体 NとArial、コードはConsolas、数式はLatin Modern Mathを使用します。
コードは`listings`で組み、字下げ、`*`・`%`・`==`などの演算子、半角引用符をそのまま表示します。数学の総和・二重和・累乗・漸化式はTeXの数式機能で描画します。画像化したコードや数式は使用していません。
表紙を除く本文に1〜18のページ番号を付けています。

元資料の主題・順序・4問の練習問題を引き継ぎ、次の点を整えています。

- ループ変数はループ終了時に消えるわけではないことを、実行例に即して説明。
- `or`は「少なくとも一方」であり、両方が真の場合も含むと明記。
- 総和の変数名は、組み込み関数`sum()`と重ならない`total`に変更。
- コードの字下げを1段4個の空白に統一。英語の出力文を短く、意味の明確な文に調整。
- フィボナッチ数列は`F_1 = F_2 = 1`から始まると指定。
- 倍数の個数を足す問題では、15の倍数をそれぞれの個数に含めることを明記。

## ノートブックと教材の公開

ノートブックの例はスライドと同じコード・出力です。上から順に実行し、練習問題は末尾の解答用セルに入力できます。提出対象は授業で用いたノートブックです。締切は記載していません。

GitHubへのリンクはリポジトリのトップを指定し、今週の教材の場所を`2026/week2`と案内しています。取り込み手順では実際に開いたノートブックのURLをコピーするため、特定のブランチを固定したURLは使用していません。
2026年度の資料は`2026`ブランチで管理しています。GitHubではブランチを`2026`に切り替えて参照してください。

## コンパイルと編集

LuaLaTeX、Beamer、LuaTeX-ja、fontspec、unicode-math、listings、upquoteと、指定したフォントが必要です。
`2026/week2`で実行します。

```sh
latexmk -lualatex -interaction=nonstopmode -halt-on-error slide.tex
```

各`frame`が1枚に対応します。コードを含むスライドには`fragile`を付け、コード本体を`lstlisting`に書きます。数学の式は`\(...\)`などの数式モードで書き、Pythonコードと区別してください。
コードを変更した場合は、対応するノートブックのセルと掲載出力も合わせて更新してください。
