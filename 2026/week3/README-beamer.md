[2025年度の第3回PDF](../../2025/week3/week3.pdf)を元に、[共通テンプレート](../../templates/beamer/README.md)で作成しています。表紙1枚と本文17枚の全18枚です。講義日は2026年11月6日です。

- `slide.tex`：編集用のLaTeXソース。
- `slide.pdf`：配布用PDF。
- `week3.ipynb`：スライドに対応する実習ノートブック。
- `../../templates/beamer/blue-lecture-theme.tex`：共通の表紙・見出し・フォント・ページ番号設定。

本文はUD デジタル 教科書体 NとArial、コードはConsolas、数式はLatin Modern Mathを使用します。Arialがない場合はLiberation Sans、Consolasがない場合はLiberation Monoを使います。数式はTeXで組み、画像化したコードや数式は使用しません。

元PDFの「最小公倍数」は、掲載コードと説明に合わせて「最大公約数」に修正しました。漸化式、一般項、総和の式はTeXの数式として表示します。Notebookでは総和関数の内部変数を、組み込み関数`sum()`と紛れない`total`に変更しました。関数の外からローカル変数`tmp`を参照する例は、スコープの説明として意図的にNameErrorになります。

## 追加した関数の例

`print`と`return`の違い、物理量を引数に渡す例、タプルで複数の値を返す例、関数を組み合わせる例、簡単な入力での確認を追加しました。質量または速度を2倍にする短い実習もあります。再帰関数は発展として最後に配置し、元の総和・フィボナッチ数列・素数判定の実習を残しています。

自由落下の例では空気抵抗を無視し、静止状態から位置`x = 0`で落下を始め、下向きを正とします。`g = 10.0 m/s^2`は教材の計算例のための近似値です。時間は秒、位置はメートル、速度はメートル毎秒、運動エネルギーはジュールで表します。

## コンパイルと編集

LuaLaTeX、Beamer、LuaTeX-ja、fontspec、unicode-math、listings、upquoteと、利用可能な指定フォントが必要です。`2026/week3`で実行します。

```sh
latexmk -lualatex -interaction=nonstopmode -halt-on-error slide.tex
```

各`frame`がスライド1枚に対応します。コードを含むスライドには`fragile`を付け、コード本体を`lstlisting`に書きます。数式は数式モードで書き、Pythonコードと区別してください。コードを変更した場合は、対応するNotebookのセルと出力も合わせて更新してください。
