本文11ページ「整数と浮動小数点の演算」は、整数同士・小数同士・混在する足し算の結果と型、`/`・`//`の結果を比較しています。

## コンパイル

TeX Liveなど、日本語対応のLuaLaTeX、Beamer、LuaTeX-jaを含む環境を使用します。
日本語は「UD デジタル 教科書体 N」（通常・太字）、英数字はArial、コードにはConsolas、数式にはLatin Modern Mathを使用します。
コンパイルするPCにもこれらのフォントが必要です。PDFを閲覧するだけならインストールは不要です。
`2026/week1` ディレクトリで次を実行してください。

```sh
latexmk -lualatex -interaction=nonstopmode -halt-on-error slide.tex
```

`latexmk` がない場合は `lualatex slide.tex` を2回実行してください。
Overleafなど別の環境では、LuaLaTeXを選択するだけでなく、同じフォントを利用できるようにする必要があります。
共通設定の `../../templates/beamer/blue-lecture-theme.tex` も必要です。
フォントファイルを配置して利用する場合は、そのファイル名に合わせて共通設定のフォント指定を変更してください。
