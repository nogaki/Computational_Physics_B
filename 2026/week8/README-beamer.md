## 内容・例・演習

独立標本で被積分関数の分散が有限なら、モンテカルロ標本平均の標準誤差は$O(N^{-1/2})$です。この収束次数は次元に直接依存しませんが、誤差係数や高次元単位球の標本ヒット率は次元に依存することを明記しています。MCMC標本は正の自己相関では実効標本数が履歴数より小さくなり、負の自己相関では大きくなる場合もあることを説明し、次回につなげています。

正弦関数の積分は$N=10^2,\ldots,10^6$、円内の点の可視化は1,000点、$\pi$推定は最大500,000点で固定シードを使います。標準正規分布のメトロポリス連鎖は、初期値0・一様な提案幅$[-1,1]$で50,000ステップです。図の再生成スクリプトとNotebookは同じ乱数シードと生成順を使います。

2025年度NotebookのPythonループは$10^8$標本まで含んでいました。実行時間を抑えてRun Allしやすくするため、独立標本をNumPyでベクトル化し、最大$10^6$標本で収束を観察する形にしています。メトロポリス法の例も、分布の再現を確認できる50,000ステップにしています。

Notebook末尾の演習セルは空欄です。

1. $d$次元単位球の体積を推定し、$\pi^{d/2}/\Gamma(d/2+1)$と比べる。
2. 二峰性の作用$S(x)=-\log(e^{-(x-3)^2/2}+e^{-(x+3)^2/2})$からMCMC標本を生成する。
3. 疑似乱数のシード・周期・統計的性質を調べる。

## PDFと図の再生成

`2026/week8`で実行します。

```sh
MPLCONFIGDIR=/tmp/weeks6-8/mpl python3 make_figures.py
TEXMFVAR=/tmp/weeks6-8/texmf-var TEXMFCACHE=/tmp/weeks6-8/texmf-var \
  latexmk -lualatex -interaction=nonstopmode -halt-on-error -outdir=.beamer-build slide.tex
cp .beamer-build/slide.pdf slide.pdf
```

図はNumPyとMatplotlibで生成します。Notebook実行にはNumPy、Matplotlibが必要です。LuaLaTeX、Beamer、LuaTeX-jaと共通テーマのフォントが必要です。
