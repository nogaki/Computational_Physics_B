# 青い表紙・青い見出し線のBeamerテンプレート

第1回のデザインを共通化した、4:3・日本語対応のテンプレートです。

- `blue-lecture-theme.tex`: 共通のデザイン・フォント設定
- `template.tex`: コピーして使うひな形（表紙と通常スライドの2枚）
- `template.pdf`: ひな形の表示見本

日本語にはUD デジタル 教科書体 N、英数字にはArialを使います。
数式にはLatin Modern Mathを使い、TeXの数式機能で組版します。
青い表紙の背景は左右のページ端から1mmずつはみ出し、細い隙間を防ぎます。
通常スライドには中央の題名と、その下にページ幅の44%の青線が付きます。
右上には講義名と講義回、表紙では日付も表示します。
右下には「現在のページ / 総ページ数」を表示します。表紙には番号を付けず、総ページ数にも含めません。本文から1として数え、段階表示では同じスライド番号を保ちます。
表紙の `frame` には `[t,noframenumbering]` を指定してください。
標準の本文は12pt、スライド題名は18pt、表紙の講義名は32pt、講義回は20ptです。
箇条書きは1段目が青丸、2段目・3段目が黒いハイフン（-）です。`itemize` を入れ子にすると自動で切り替わります。

## 次の講義で使う

1. `template.tex` を、例えば `2026/week2/slide.tex` にコピーします。
2. 共通設定の読み込みを次の相対パスに変更します。

   ```latex
   \input{../../templates/beamer/blue-lecture-theme.tex}
   ```

3. `\title`（講義名）、`\subtitle`（講義回）、`\author`（著者）、`\date`（日付）を変更します。
4. 通常スライドの `frame` を必要な枚数だけ追加します。

```latex
\begin{frame}{新しいスライドの題名}
  本文
\end{frame}
```

コンパイルは、各 `slide.tex` があるディレクトリで行います。

```sh
latexmk -lualatex -interaction=nonstopmode -halt-on-error slide.tex
```

このディレクトリで見本を作り直す場合は、`slide.tex` を `template.tex` に置き換えて実行します。

## 別のプロジェクトで使う

`template.tex` と `blue-lecture-theme.tex` を同じディレクトリへコピーすれば、そのまま使えます。
LuaLaTeX、Beamer、LuaTeX-jaと、UD デジタル 教科書体 N（通常・太字）・Arialが必要です。
別のPCやOverleafでコンパイルする場合も、同じフォントを利用できるようにしてください。
生成済みのPDFを閲覧するだけならフォントのインストールは不要です。

## デザインを変更する

数式は、文中では `\(y=e^{-x}\sin x\)`、独立した行では `\[x=\frac{\pi}{2}\]` のように書きます。
分数・累乗・平方根・関数名には、それぞれ `\frac{a}{b}`、`x^2`、`\sqrt{x}`、`\sin x`・`\log x` などを使います。
`unicode-math` とLatin Modern MathはTeX Liveに含まれています。

`blue-lecture-theme.tex` の設定を変更すると、そのファイルを読み込む講義すべてに反映されます。

| 設定 | 現在の値 |
|---|---|
| 表紙の青 `courseblue` | `4472C4` |
| 見出し線の青 `ruleblue` | `8FAADC` |
| 見出し線の長さ | `0.44\paperwidth` |
| 見出し線の太さ | `0.5pt` |
| 本文の左右余白 | `9mm` |

特定の講義だけ配色を変更する場合は、共通設定の読み込み後に色を上書きできます。
長い講義名には `\title[右上の短い表示名]{表紙に表示する講義名}` のように短縮名を指定できます。
このテンプレートは4:3で調整しています。縦横比やタイトルの行数を変えた場合は、PDFの配置を確認してください。
